# User Stories – TaskFlow

1. **Add Simple Task:** As a student, I want to add a simple task with a title and priority (1–5) so I can keep track of everyday to-dos.
2. **Add Deadline Task:** As a student, I want to add a task with a due date so that upcoming university deadlines automatically receive higher urgency.
3. **Switch Sorting View:** As a user, I want to switch between sorting tasks by urgency score and alphabetically by title so I can either focus on what is urgent or quickly find a task by name.
4. **Complete or Remove Tasks:** As a user, I want to mark tasks as completed or delete them so my board stays up to date.
5. **Persist Data Between Runs:** As a user, I want my tasks automatically loaded at startup and saved to disk when I save or exit so I never lose my list.
